# Bugs found and resolved

## 1. Client-name duplicate check

`TaxApiService.createClient()` previously used the duplicate-name condition backwards.
It has been corrected so a new client name can be created and an existing name returns
`null`, which the controller exposes as HTTP 409 Conflict.

## 2. Item ID getter

The item ID getter was reviewed and confirmed to return the stored `id` field. Tests verify
that item responses preserve the ID, name, and category when the price is updated.

## 3. Tax amount calculation

The tax quote calculation previously added the pre-tax price into the tax amount. It now
calculates `taxAmount = price * taxRate` and `total = price + taxAmount`. Tests cover both
item-based and direct-price tax quotes.
